# SHARE-001 — Aperçu social Open Graph

## Statut

`DONE`

## Constat

La racine de production répondait correctement au robot Messenger, mais son
HTML ne contenait aucune balise `og:*` ou `twitter:*`. Le manifeste et les
icônes PWA ne permettent pas, seuls, de construire un aperçu de lien.

## Objectif utilisateur

Obtenir, au collage d'un lien Capsule dans Messenger ou un lecteur Open Graph,
une carte avec l'identité de l'application, son icône et une miniature lisible.

## Périmètre

- métadonnées Open Graph et Twitter/X globales ;
- URL canonique de production explicite ;
- carte PNG 1 200 × 630 générée par Next.js depuis l'identité existante ;
- métadonnées dédiées aux notes publiquement partagées ;
- titre public de la note, description et visuel génériques ;
- tests unitaires, rendu local réel et documentation du cache Messenger.

## Hors périmètre

- génération d'une image depuis le corps ou les images d'une note ;
- publication d'une URL signée dans une métadonnée ;
- purge automatique du cache Meta ou intégration à son API ;
- migration Supabase, variable Vercel ou dépendance supplémentaire ;
- modification du manifeste, du service worker ou des icônes installées.

## Critères de sortie

- la racine expose au moins les quatre propriétés Open Graph fondamentales ;
- le visuel répond en PNG 1 200 × 630, avec texte alternatif ;
- la carte reste lisible, sans contenu coupé ni erreur console ;
- les liens `/share/<token>` valides annoncent le titre déjà public, jamais le
  corps, les tags, les images ou une URL signée ;
- un token invalide ou révoqué annonce explicitement une note introuvable ;
- les lecteurs Twitter/X disposent d'une grande carte de repli ;
- lint, tests, build et audit npm élevé sont verts ;
- PR protégée fusionnée, Vercel `READY` et smoke robot production conformes.

## Validation locale

- diagnostic de référence : `200` mais zéro balise sociale sur la production
  antérieure ;
- lint propre, 98/98 tests dans dix-sept fichiers et build Next.js 16.3.3 ;
- racine locale : 15 balises sociales, URL absolues et dimensions annoncées ;
- `/opengraph-image` : `200`, `image/png`, signature PNG, 78 628 octets et
  dimensions réelles 1 200 × 630 ;
- token inexistant : 15 balises, titre **Note introuvable — Capsule** et image
  générique ;
- contrôle visuel à 1 200 × 630 : identité, textes et mini-interface lisibles,
  sans alerte ni erreur console ;
- `npm run validate` complet vert et audit npm élevé à zéro vulnérabilité.

## Rollback

Réassigner le dernier déploiement Vercel sain. Aucune donnée ni migration n'est
à restaurer.
