# PRINT-001 — Impression et PDF fidèle

## Statut

`REVIEW_REQUIRED`

## Objectif utilisateur

Imprimer une note enregistrée ou l'enregistrer en PDF depuis le dialogue système,
avec un rendu lisible du Markdown et des images, sur ordinateur comme depuis la
PWA iPhone/iPad.

## Périmètre

- action `Imprimer / PDF` depuis le détail d'une note ;
- aperçu papier clair avec titre, date, tags, contenu Markdown et images ;
- rendu Markdown non interactif sans visionneuse ni commandes applicatives ;
- détection des références privées manquantes et préparation explicite de
  toutes les images avant l'ouverture du dialogue système ;
- pagination A4, marges, règles anti-coupure et adaptation des contenus longs ;
- titre de document sûr pour suggérer un nom de fichier utile ;
- notice indiquant qu'un PDF enregistré sort du périmètre de protection de
  Capsule ;
- aide embarquée et documentation technique mises à jour.

## Hors périmètre

- moteur PDF serveur ou dépendance de capture raster ;
- stockage, synchronisation ou envoi automatique du PDF ;
- impression d'un brouillon non sauvegardé ou d'un résumé IA temporaire ;
- impression directe d'une note publique partagée ;
- signature électronique, scellement ou valeur probatoire ;
- migration Supabase ou nouvelle variable Vercel.

## Critères de sortie

- action accessible dans les détails carte et liste, absente pendant l'édition ;
- aperçu utilisable aux largeurs desktop et mobile sans débordement horizontal ;
- aucune impression tant qu'une image référencée est absente ou non décodable ;
- progression et erreur explicites, avec annulation et nouvelle tentative ;
- titre, tags, date, Markdown, liens et légendes présents ;
- notes sans image, avec plusieurs images et proches de 20 000 caractères
  correctement paginées ;
- interface, ombres, boutons, visionneuse et contenu temporaire exclus du papier ;
- thème sombre imprimé sur fond clair et contenu sélectionnable ;
- fermeture du dialogue système ou du dialogue Capsule sans modifier la note ;
- recette Chrome desktop, viewport mobile et PWA/Safari documentée ;
- lint, tests, build et audit npm verts ;
- PR protégée fusionnée, Vercel `READY` et smoke public conforme.
