# HELP-001 — Centre d’aide contextuel

## Statut

`REVIEW_REQUIRED`

## Objectif utilisateur

Rendre les fonctionnalités et réglages de Capsule compréhensibles sans quitter
l’application, sur ordinateur comme sur iPhone ou iPad installé en PWA.

## Périmètre

- centre d’aide statique, recherchable et navigable au clavier ;
- démarrage rapide court, facultatif et réouvrable ;
- guides notes/Markdown, images, organisation, partage, confidentialité, PWA,
  IA BYOK, raccourcis et dépannage ;
- accès depuis le menu, la palette, l’éditeur, les états vides et les paramètres
  IA ;
- progression de démarrage stockée uniquement dans le navigateur, sans donnée
  métier ni synchronisation Supabase.

## Hors périmètre

- assistant conversationnel ou génération IA de documentation ;
- visite forcée par overlays positionnés sur l’interface ;
- nouvelle table, migration ou donnée de profil ;
- modification des notes, images, clés ou paramètres existants.

## Critères de sortie

- recherche insensible aux accents et résultat vide explicite ;
- sections atteignables par boutons nommés et état actif annoncé ;
- checklist réinitialisable et masquable sans bloquer l’application ;
- aide contextuelle ouvrant directement la bonne section ;
- dialogue accessible, responsive, sans débordement aux viewports de recette ;
- contenu présent dans le bundle et disponible avec le shell PWA ;
- lint, tests, build et audit npm verts ;
- PR protégée fusionnée, Vercel `READY` et smoke public conforme.

## Rollback

Le sprint ne crée aucun état serveur. Le rollback applicatif réassigne le
dernier déploiement sain ; la seule préférence locale peut être supprimée sans
impact sur les données métier.

## Validation locale

- `npm run validate` : lint propre, 13 fichiers et 64/64 tests, build Next.js
  16.3.3 réussi avec dix routes générées ;
- `npm run security:audit -- --audit-level=high` : zéro vulnérabilité ;
- recette Chrome authentifiée : menu, palette, état vide, éditeur Markdown,
  guide images et paramètres IA ouvrent le bon contexte ;
- recherche accentuée, résultat vide, progression 1/5 persistante,
  masquage/réinitialisation, thèmes clair/sombre, fermeture `Échap` et
  restitution du focus validés ;
- dialogue mesuré à 1 024 px sans débordement horizontal ; les règles 390 px,
  défilement horizontal des rubriques et zone sûre iOS sont couvertes par test
  statique ;
- compte synthétique supprimé avec zéro note, tag, réglage IA, quota ou objet
  Storage résiduel.

La livraison reste soumise à la PR, au `Quality gate`, à Vercel `READY` puis à
la recette de production.
