# AI-002-R1 — Fiabilité des notes longues

## Statut

`REVIEW_REQUIRED`

## Déclencheur

Retour utilisateur : mise en forme courte efficace, mais attente sans résultat
sur une note longue jointe, obligeant à annuler manuellement.

## Critères de sortie

- le cas réel de 18 389 caractères termine avant le timeout client ;
- l'attente affiche sections, temps écoulé, annulation et échéance ;
- aucune sortie partielle ou tronquée n'est applicable ;
- images, nombres, URL et tâches sont restaurés exactement ;
- la note et le modèle choisis par l'utilisateur restent inchangés ;
- aucune migration, donnée Supabase ou nouvelle persistance ;
- tests, build, audit, smoke authentifié, PR et production verts.

## Implémentation

- seuil long : 10 000 caractères ; sections de 5 000 maximum ; concurrence 2 ;
- budget agrégé des sections borné et reprise unique d'une section invalide ;
- thinking désactivé sur Sonnet/Opus 5 pour la seule mise en forme ;
- marqueurs opaques aléatoires pour images et faits structurés ;
- annulation propagée, timeout client 100 secondes et erreur sûre.

## Validation locale

- `npm run validate` : lint, **80/80 tests** et build Next.js 16.3.3 verts ;
- audit npm élevé : zéro vulnérabilité ;
- cas réel direct : succès en 38,9 secondes ;
- smoke route authentifiée : **40/40**, cas réel en 35,4 secondes et nettoyage
  synthétique contrôlé ;
- recette visuelle bureau : aucun débordement, compteur, annulation et retour de
  focus conformes ; harnais supprimé.

## Rollback

Rollback applicatif vers le déploiement AI-002 initial. Aucun schéma, secret,
réglage ou contenu de note n'est créé par ce correctif.
