## 5. Produit et architecture à conserver

Next.js App Router, JavaScript, React, Supabase Auth/PostgreSQL/Storage, Vercel
depuis GitHub main. Style neo-brutaliste fonctionnel ; éviter une réécriture de
app/page.js. Les fonctions livrées couvrent :

- notes Markdown, cartes/liste/Kanban, tags, recherche et palette de commandes ;
- images privées par fichier, collage et dépôt, compression et galerie ;
- duplication, suppression, partage signé et aperçu social générique ;
- PWA iPhone/iPad, aide contextuelle, footer de version et À propos ;
- BYOK Anthropic session/Vault, choix du modèle, résumé et mise en forme ;
- impression/PDF par le dialogue natif, sans fichier stocké par Capsule.

Frontières impératives :

- RLS et propriété des notes/images ; bucket privé note-images.
- Références Markdown `capsule-image/<uuid>`, aucune URL signée persistée.
- Upload différé jusqu'à la sauvegarde ; duplication avec de nouveaux objets.
- Aucune note, image privée, réponse API ou clé IA dans le cache PWA.
- Clé Anthropic en mémoire de session ou Vault ; jamais en stockage navigateur
  persistant. Le serveur n'utilise pas implicitement la clé partagée historique.
- Résultat IA appliqué explicitement au brouillon, sauvegarde manuelle séparée.
- lib/supabase-admin.js exclusivement serveur ; aucune clé dans NEXT_PUBLIC.
- PR + Quality gate avant main, puis contrôle de production et smoke.

Les migrations Supabase sont déjà versionnées et déclarées appliquées dans les
contrôles historiques. Trois versions : 20260826000000, 20260826120000 et
20260827094500. Ces résultats historiques ne sont pas un nouvel audit distant.
Ne rien rejouer ; lire les SQL et prévisualiser avant toute évolution de base.
