## Architecture recommandée pour les images

Je déconseille d’enregistrer les images en Base64 dans `contenu`, ainsi qu’un bucket public pour des notes personnelles.

```text
Fichier ou collage
       ↓
éditeur de note + aperçu local
       ↓ sauvegarde
bucket privé Supabase + table note_images
       ↓
jeton stable dans le Markdown
![description](capsule-image/<uuid>)
       ↓
MarkdownRenderer → URL signée temporaire
       ├── utilisateur authentifié
       └── page publique, seulement si la note est partagée
```

Supabase recommande les buckets privés avec RLS et URL signée pour les ressources sensibles. Les restrictions de taille et de types MIME peuvent être imposées directement sur le bucket. [Buckets privés](https://supabase.com/docs/guides/storage/buckets/fundamentals), [contrôle d’accès Storage](https://supabase.com/docs/guides/storage/security/access-control).

Cible fonctionnelle proposée :

- ajout par sélecteur de fichier ;
- collage direct d’une image dans le champ au niveau du curseur ;
- JPEG, PNG et WebP, 5 Mio maximum ;
- plusieurs images possibles dans une note ;
- aperçu avant sauvegarde ;
- bucket privé `note-images` ;
- table `note_images` pour le chemin, le type, la taille et la relation avec la note ;
- duplication réelle des objets lors de la duplication d’une note ;
- suppression Storage avant suppression définitive de la note ;
- nettoyage des fichiers si une sauvegarde échoue ;
- affichage dans les vues détail, modale et partage public ;
- vignette limitée dans les cartes pour préserver la mise en page mobile.

La limite de 5 Mio reste sous les 6 Mo recommandés pour les envois standards Supabase. [Standard uploads](https://supabase.com/docs/guides/storage/uploads/standard-uploads). La suppression devra passer par l’API Storage pour ne pas créer d’objets orphelins. [Suppression des objets](https://supabase.com/docs/guides/storage/management/delete-objects).

Le collage peut être intercepté avec l’événement `paste`, puis l’image récupérée comme `File` via `clipboardData.items`. [Événement paste](https://developer.mozilla.org/en-US/docs/Web/API/Element/paste_event), [getAsFile](https://developer.mozilla.org/en-US/docs/Web/API/DataTransferItem/getAsFile).

Pour les pages partagées, une clé Supabase serveur sera nécessaire afin de signer les images après validation du token de partage. Elle restera exclusivement côté serveur/Vercel. [Clés Supabase serveur](https://supabase.com/docs/guides/getting-started/api-keys).
